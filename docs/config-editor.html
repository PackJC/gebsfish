Drop in the JSON files from your server's Gebs folder, tune everything visually, download them back. No text editor needed.

Load your config files

Everything happens in your browser — nothing is uploaded to any server, and your files never leave your computer.

🎣
Drag & drop your JSON files here or click to browse — load one file or all four at once fish.json bait.json general.json junk.json
Where do these files live? The mod generates them on first server start, inside your server's profile folder (the directory named by your server's -profiles= launch parameter):
…\YourDayZServer\profiles\Gebs\ → general.json bait.json fish.json junk.json
Safe to edit. This editor only changes the values you touch. Every other field — including the built-in …Info documentation and the ConfigVersion stamp — is preserved exactly, so the mod's additive update system keeps working. Fields from newer mod versions that this editor doesn't know about yet are kept untouched too.

🐟 Fish — fish.json

Per-species tuning: how common each fish is, where and how it's caught, meat yield, weather & temperature behavior, and its 24-hour bite rhythm.

🪱 Bait & Lures — bait.json

Pick a bait, then set how strongly it attracts each fish. 1.0 is neutral — higher means that fish loves this bait, lower means it ignores it.

⚙️ General — general.json

Global systems: weather & time-of-day buffs, moon phase, water temperature, treasure, predators, foraging, recipes, and logging.

🗑️ Junk — junk.json

Items a rod can drag up instead of a fish (nets and traps never catch junk). The junk share sets how often that happens; each item's weight (0–25) sets how often it turns up among the junk; health is rolled in the min–max range.

🎯 What will bite?

Pick a map, a time, the weather and what's on the hook to see the odds the server will use for each catch, worked out with the mod's own math from the files you loaded. It only reads them: nothing here changes your config.
